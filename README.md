In this project I scraped all of my followers on instagram who I also follow. Then using Playwright I scraped everyone each of them followed that was already on the list. I used this data to make a PyVis visualization. I analyzed this graph and using, PyTorch Geometric, tested some simple GNNs on it. A Blog about this whole process can be found on my website https://sampease.github.io/instagram-network.html

This project was Inspired by and initially cloned from: https://medium.com/@maximpiessen/how-i-visualised-my-instagram-network-and-what-i-learned-from-it-d7cc125ef297 but ended up all being new code

All analysis can be found in the Jupyter Notebook https://github.com/SamPease/instagram_network_analysis/blob/master/graph_vis3.ipynb
